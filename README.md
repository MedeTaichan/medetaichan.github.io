# [めでたいのアプリ系ページ](https://app.medetaich.com/)
めでたいのGitHub用ホームページです。[めでたいのページ](https://www.medetaich.com/)とは異なり、HTML系ゲームや配布物、プロジェクトを置く静的サイトとして運用しています。  
アクセスすると、制作したゲームなどへリンクが貼られています。自由に見たり、リポジトリを参照したりしてみてください。
## 404ページについて
サイト内で存在しないページへアクセスしようとすると、[404.htmlのページ](https://app.medetaich.com/404.html)が呼び出されます。
